# 首版实现与验收

日期：2026-11-12。这里记录已实现的行为，初始架构规划中的后续能力不自动视为已完成。

## 已接通

- 独立 Python 包、依赖锁文件、配置示例、环境变量模板、CLI、本地 FastAPI 入口与 Python API。
- SQLite 不可变快照，内容 hash 覆盖正文、metadata、向量和关系。构建完成后原子切换 active 指针，旧快照保留。中文可选 Milvus 镜像，逐条核对 payload 和存储精度下的向量；英文对上游三个 collection 的实际记录做摘要校验。
- 英文依赖固定提交，Jev 1.13 两阶段保留在上游内部。适配层校验版本、配置、索引，直接调用原生 query/retrieve。原文重复时保留来源别名；metadata filter 同时约束引用映射，不能把过滤外的同文来源返回给用户。
- 中文解析与结构切分迁移；片段携带原文位置、章节父块 ID、同逻辑文章邻块。自定义 tokenizer 有独立身份指纹，默认字符预算不冒充模型 token 预算。
- 中文完整流程：问点规划 → 原问题与子问题的 dense/BM25/向量关系召回 → 图扩展 → 可选关系重排 → 原文问点选证 → 引文逐字定位 → 预算内覆盖选择 → 有限补查 → 回答 → 引用/数字规则与模型核验 → 最多一次回答修复。
- 中文 `single-stage` 和 `two-stage` 共用索引，区别为是否使用模型筛选关系。两者都保留最终原文选证。关系重排失败回退、查询实体失败、抽取正常为空与失败均可区分。
- 原文可检索不依赖关系抽取成功。索引持久化缓存支持恢复已完成的抽取/向量任务；`build(retry_failed=True)` 可重试失败抽取。查询 trace 显示索引抽取失败片段。
- 独立模型角色和兼容 HTTP 服务；可选 `/rerank` 服务接口。正文候选不会在适配层悄悄截断。
- 评测生成/评分分开持久化，配置指纹、快照固定、互斥运行、写断末行恢复、失败生成续跑及指定题目重跑。评分失败重试复用答案，不重新调用生成。按来源计算候选/最终覆盖，支持人工标注的字面事实覆盖；gold 不进入查询模型。
- 迁入历史公开精简记录、复算脚本与 CRUD 数据准备脚本。历史千题复算仍为 791/1000；原始日志和数据集留在旧项目。

## 验证范围

最终在新项目目录及其锁定环境运行：**38 passed、1 skipped，另有 4 个 subtests passed**。唯一跳过项为缺少 Tesseract 的真实扫描 OCR 测试。Milvus Lite 的依赖弃用提示不影响通过结果。

完整命令为 `uv run pytest -q`，使用模拟模型、合成文档、真实 SQLite/Milvus Lite 和本地 HTTP 服务。测试网络保护禁止非本地连接，没有付费模型调用。

验证包括：

1. 英文适配层与直接调用固定上游的答案、片段顺序一致，query/retrieve 共用索引；错误保持失败语义。
2. 中文单/两阶段复用同一关系索引；关键事实引文定位、邻块定向补查不跨文章、漏答修复仅一次。
3. 同数量正文、metadata、关系或向量被修改时，模型调用前拦截；真实 Milvus 向量变动也被发现。
4. 重复正文来源别名与过滤隔离；混合语言知识库不能自动静默选择一条链。
5. 抽取失败可见；已完成索引任务恢复时不重复抽取；失败任务可重试。
6. 评分中断恢复答案、指定题目补跑、配置变化阻止续跑、末行写断恢复及来源/事实诊断。
7. CLI 经实际 HTTP 适配器完成建索引和问答；FastAPI 路由及索引错误状态。
8. 迁移的编码、句界、表格、DOCX、PDF 布局测试。真实扫描 OCR 取决于可选 Tesseract 和语言包，缺失时显式跳过。

这里验证的是工程行为。模拟模型的完整回答不能作为中文准确率、模型效果或英文基准复现成绩。

## 当前实现边界与后续工作

- 英文接入原生 1.13 可运行档案。没有另写上游 1.14 冻结实验的服务适配，也没有重新评测英文准确率。
- 中文嵌入和重排模型由服务接口注入；已经接通接口，尚未在真实 BGE-M3/更强模型上跑效果实验。cross-encoder 默认仅重排，不缩减候选，避免在未评测前增加丢证因素。
- BM25 使用中文字符与双字词项、英文/数字词项。可继续比较更好的分词和 learned sparse；multi-vector 尚未实现。
- 中文关系和元数据加载到进程内，关系向量在本地精确打分，Milvus 主要承载原文向量召回。大规模关系向量独立 collection 与服务端邻接访问属于下一步性能实现，当前不是无限规模索引方案。
- 逻辑文章边界由输入的 `document_id` 或来源确定。已禁止邻块跨明确边界；新闻拼接自动检测、低质量标题识别仍待做。父块读取目前由同章节子块组成，不是额外的摘要索引。
- 核验发现缺证时返回可追踪的 partial；查询阶段已有最多两轮补查，核验阶段暂不再开启第二套检索循环。数值复制检查为保守规则，不是通用算术验证器。
- 当前更新通过完整文档清单构建新快照并切换，已完成任务可复用。增量并发 ingestion、多实例任务调度、PostgreSQL 和对象存储尚未实现。英文重建使用新 prefix，英文建库恢复沿用上游能力，没有额外添加逐任务检查点。
- HTTP API 默认仅监听本地，无多用户认证和权限管理；生产接入需由宿主系统提供这些能力。
- `both` 联合检索明确未实现，后续作为独立档案接入，避免改变英文默认行为。
- 500 题复盘中的 59/53 题可作为下一轮开发回归，但不再视为未见测试集。本次没有运行这些题的付费生成/评分，也没有读取或复制旧密钥。
